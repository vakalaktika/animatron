# Illustration examples: scope of evidence

The Garden glider and Goodnight SVG/rig files in this folder are technical fixtures for editable groups, registration and motion. The Garden drawing does not establish fidelity to the Detailed style anchor. Its rasterized derivative tests attachments; it is not a generated-illustration benchmark.

For the generated-artwork production proof, see `examples/illustrated-scenes/sunroom-glider/` in the owning Animatron PR: https://github.com/vakalaktika/animatron/pull/25. It includes the generated finished still, supervised clean plate/transparent parts, registered replacement heads, part inventory, importable composition, application-rendered MP4 and candid visual/technical findings. Keep generated candidates separate from approved character/style authorities. Original and Detailed retain their existing distinct references.
